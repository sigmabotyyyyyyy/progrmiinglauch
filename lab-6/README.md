# Лабораторная работа №6

**JavaScript DOM и события**  
**Уровень:** средний  
**Вариант:** №8 — таблица студентов.

## Задание
Форма добавляет строку с именем и баллом.
Каждая строка имеет кнопку удаления.

## Реализовано
- отдельные `index.html`, `style.css`, `script.js`;
- `querySelector()` / `querySelectorAll()`;
- события `click`, `keydown`, `input`;
- динамическое создание строк через `createElement()`;
- удаление через `remove()`;
- изменение `textContent`, `style`, `dataset`;
- дополнительная функция: поиск и сортировка по баллу.

## Схема
`событие → обработчик → изменение DOM`

Пример: `click по "Добавить" → addStudent() → создается новая строка таблицы`.

## Тестовые сценарии
1. Имя `Аян`, балл `85` → строка добавляется.
2. Пустое имя → выводится ошибка.
3. Балл `101` → выводится ошибка.
4. Нажатие Enter в поле → студент добавляется.
5. Нажатие "Удалить" → строка исчезает.

## Запуск
Откройте `index.html`.
