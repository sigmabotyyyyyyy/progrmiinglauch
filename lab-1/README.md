## Задание
Ввести количество секунд. Определить количество полных часов, минут и оставшихся секунд.

## Алгоритм
1. Считать количество секунд.
2. Полные часы получить целочисленным делением на 3600.
3. Минуты получить из остатка после часов.
4. Остаток секунд получить оператором `% 60`.
5. Вывести результат.

## Тесты
- `7384` → `2 ч 3 мин 4 сек`
- `3600` → `1 ч 0 мин 0 сек`
- `59` → `0 ч 0 мин 59 сек`

## Запуск
```bash
python3 lab1.py
```
