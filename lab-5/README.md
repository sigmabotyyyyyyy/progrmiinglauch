# Лабораторная работа №5

**JavaScript + DOM**  
**Уровень:** средний  
**Вариант:** №8 — генератор карточки студента.

## Реализовано
- `let/const`, `if`, цикл `for...of`;
- пользовательские функции;
- получение элементов через DOM;
- события `click` и `input`;
- динамический вывод карточки;
- изменение стилей через JavaScript;
- дополнительная функция: переключение оформления.

## Тестовые сценарии
1. Все поля заполнены → карточка создается.
2. Пустое имя → сообщение об ошибке.
3. Не выбран курс → сообщение об ошибке.

## Запуск
Откройте `index.html`.
