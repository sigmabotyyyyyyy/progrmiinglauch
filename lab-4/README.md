# Лабораторная работа №4

**HTML + JavaScript**  
**Уровень:** средний  
**Вариант:** №8 — форма заказа товара.

## Требования варианта
Товар (`select`), количество, способ доставки (`radio`),
дополнительные услуги (`checkbox`). Количество должно быть больше 0.

## Реализовано
- отдельные `index.html`, `style.css`, `script.js`;
- обработка `submit` и `event.preventDefault()`;
- JavaScript-валидация;
- понятные сообщения рядом с полями;
- итоговые данные без перезагрузки;
- дополнительная функция: расчет итоговой стоимости.

## 5 тестовых сценариев
1. Все данные корректны → заказ принят.
2. Товар не выбран → ошибка.
3. Количество `0` → ошибка.
4. Отрицательное количество → ошибка.
5. Не выбран способ доставки → ошибка.

## Запуск
Откройте `index.html` в браузере.
