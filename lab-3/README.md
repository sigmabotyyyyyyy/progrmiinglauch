# Лабораторная работа №3 — ООП

**Язык:** Python  
**Уровень:** средний  
**Вариант:** №8 — `Product`

## Задание
Класс `Product`: название, цена, количество.
Реализовать изменение цены, добавление количества и вычисление стоимости запасов.

## Реализовано
- `__init__()` — создание товара;
- `change_price()` — изменение цены;
- `add_quantity()` — увеличение количества;
- `stock_value()` — стоимость запасов;
- `info()` — удобный вывод информации;
- дополнительный атрибут `category`;
- создано 3 объекта;
- показано изменение состояния объектов.

## Тестовые сценарии
1. Изменение цены клавиатуры с 25000 до 23000.
2. Добавление 3 мышей к исходным 7.
3. Изменение цены и количества наушников.

## Запуск
```bash
python3 lab3.py
```

## Вывод
Работа демонстрирует создание классов и объектов, методы,
изменение состояния и вычисления на основе атрибутов объекта.
