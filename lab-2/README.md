# Лабораторная работа №2

**Дисциплина:** Языки и технология программирования  
**Язык:** Python  
**Уровень:** средний  
**Вариант:** №8

## Задание
Ввести количество секунд. Представить его в формате `часы:минуты:секунды`.

## Алгоритм
Используются только линейные конструкции, арифметические операции,
`//` и `%`, без `if`, циклов, списков и пользовательских функций.

## Тесты
- `7384` → `02:03:04`
- `3661` → `01:01:01`
- `45` → `00:00:45`

## Запуск
```bash
python3 lab2.py
```

## Вывод
Программа корректно преобразует общее количество секунд
в формат часов, минут и секунд.
